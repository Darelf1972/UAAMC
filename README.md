# UAAMC Corporate Website

Static multi-page website for Universal Agri-Agra & Minerals Corporation.

## Files

- `index.html` — Home
- `about.html` — About Us
- `services.html` — Core Business Areas
- `approach.html` — Our Approach
- `contact.html` — Contact
- `styles.css` — Shared styling
- `script.js` — Mobile navigation behavior
- `assets/uaamc-logo.png` — Company logo
- `assets/favicon.png` — Favicon

## GitHub Pages

1. Upload the contents of this folder to the root of the GitHub repository.
2. Commit and push to the selected branch, usually `main`.
3. In GitHub, open **Settings → Pages**.
4. Select **Deploy from a branch**.
5. Choose the branch and `/root` folder, then save.
6. GitHub will provide the temporary `github.io` address.
7. A custom domain can be connected later under the same Pages settings.

## Before launch

Replace the placeholder contact details in all HTML pages:

- `info@uaamc.example.com`
- `Manila, Philippines`
- `Company details to be finalized upon confirmation.`

The site intentionally uses only the supplied logo and original CSS/SVG illustrations. No external image files are required.
