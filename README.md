## GitHub Pages

1. Upload the contents of this folder to the root of the GitHub repository.
2. Commit and push to the selected branch, usually `main`.
3. In GitHub, open **Settings → Pages**.
4. Select **Deploy from a branch**.
5. Choose the branch and `/root` folder, then save.
6. GitHub will provide the temporary `github.io` address.
7. A custom domain can be connected later under the same Pages settings.
